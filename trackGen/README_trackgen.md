# Trackgen
A tool to generate tracks and background in a 4 layer tracker.
See comments in trackGen1.C

## Track Generator:
Makes tracks for visualisation or dumping to tree as std:vec.
```
// Ken Livingston   -   Created May 2026 
// Toy Timepix4 tracker model 
// signal events from target disk or ring LTARG to L0
// BG events isotropic with hits in layers L0 and L1
// .... something like this                                                                   
//                                                                                     
//    ^ y-axis                                                      
//
//    :   Tracker                                                                                        
//   L0   L1   L2   L3                                                                            
//    |    |    |    |                                                                      LTARG ||
//    |    |    |    |                                                                            ||
//    |    |    |    |                                                                            ||  
//____|____|____|____|_____________________________________//______________________________________:___ z axis
//   0:(x,y,z) = (0,0,0)                                                                           :
//    :<-------------------------------------------------- // ------------------------------------>:
//    :  layerz[0-3]                         layerz[4]                                              
//                                                                                                 

// To run:
// root[] .L trackGen.C
// root[] trackSim(n_signal, n_bg, n_singles, comb)
// where:
// n_signal (default = 100)
// n_bg     (default = 100)
// n_singles (default = 0 )
// comb     (defauls = 1 ie do combinatorials)
```
trackGen.C - see comments in the code.

There are 3 types of "track".

Type 0: Signal
   Generated by picking a random point on the target and a random point on layer 0
   and joining the dots, and projecting through other layers.

Type 1: Background
   Generated by picking a random point on layer 0 and a random on layer 0
   and joining the dots, and projecting through other layers.

Type 2: Singles
   Random single hits. A random hit anywhere on one of the layers only.

## Contains 2 user functions:
#### trackSim(int tr=10, int bg=100, int singles=0, int comb=1, int tgttype=0, double tgtr=10.0, double tgtt=2.0)

Runs a single event with multiple tracks. Call directly for visualisation. Otherwise, use runTracks() - see below.

```
tr       = no of signal  tracks
bg       = no of bground tracks
singles  = no on singles
comb     = flag do do all combinatorials for reconstructing target plane.
tgttype  = target type: 0=cross, 1=ring or disk
tgtr     = radius or length of cross (mm)
tgtrt    = width of cross or ring (mm)
```

### Plots 2 canvases.
1. Hits on Layers. Shows the all the hits on all the layers including the target plane.
2. Targ plane recon from Multiple Layers. Reconstructs ther target plane from layers 0,1 0,2 0,3 




#### void runTracks(const char *fname,int nevt=100, int tr=10, int bg=100, int singles=0, int comb=1, int tgttype=0, double tgtr=10.0, double tgtt=2.0){

Calls the above trackSim() for nevt and writes tree into fname.root, and config to fname.txt

#### Example 1
Look at hits in various combinations
```
>root 
root [0] .L trackGen.C 
root [1] trackSim(100,100,0,0)  //100 signal, 100 bg, no  singles, no combis
root [2] trackSim(100,100,0,1)  //100 signal, 100 bg, no  singles, combis
root [3] trackSim(10,100,0,1)   //10  signal, 100 bg, no  singles, combis
root [4] trackSim(10,100,100,1) //10  signal, 100 bg, 100 singles, combis
```

#### Example 2
Generate tracks to a tree. (best in batch mode)
```
>root -b
root [0] .L trackGen.C
root [1] runTracks("test0",10,10,100)  //To files "test0.root", "test0.txt", 10 events each with with 8 signal tracks, 12 bg track, 20 singles.
```
